The Orchestration Dashboard for registered targets

Electros is Elemento Cloud's orchestration dashboard—available as a native desktop app for Linux, macOS, and Windows. It provides visibility, provisioning, and remote access for workloads on the targets you register.


Register and govern AtomOS hosts, VMware ESXi 6 or 7, Proxmox VE 7 or 8, and public or private Meson cloud accounts from one interface — connected through Atomosphere.

Private Meson guides are currently available for AWS, Azure, Google Cloud, OVHcloud, UpCloud and Scaleway.

  • Group targets into scenarios and enable them for the current session

Powerful capabilities for managing hybrid and multicloud environments

Targets, scenarios and permissions

Register AtomOS, hypervisor and Meson targets; group them into reusable scenarios; enable the targets needed for the current working session; and manage organisation-level usage permissions.

Registration records a target. Enabling it for a session is a separate step and does not provision a workload.

Remote access built in

Open an embedded VNC console for long-lived virtual machines. For public-cloud Spot VMs, the Electros desktop app can open an SSH terminal to a reachable instance.

SSH Terminal is available in the desktop app and requires a running Spot VM with a reachable public IPv4 address and TCP port 22. Browser builds cannot open the desktop SSH window.

Remote access

Embedded VNC for long-lived virtual machines, and desktop SSH for reachable Spot VMs

Electros opens an embedded VNC console for long-lived virtual machines. For public-cloud Spot VMs, the desktop app can open an SSH terminal when the instance is running and reachable.

SSH Terminal is available in the desktop app and requires a running Spot VM with a reachable public IPv4 address and TCP port 22. Browser builds cannot open the desktop SSH window.

Remote access in v3.3.0:

VNC

Embedded graphical console for long-lived virtual machines. The guest must be running.

SSH

Desktop SSH terminal for a running public-cloud Spot VM with a reachable public IPv4 address and TCP port 22.

Virtual machines, storage, and networking

What the v3.3.0 desktop app can do on an enabled target

Virtual machines

  • Basic, advanced, and blueprint-based VM creation
  • Power, reboot, force-off, and deletion
  • Embedded VNC
  • AtomOS migration and backups
  • Clone non-AtomOS VMs to AtomOS
  • Attach and detach volumes and networks
  • AtomOS port forwards and port tunnels
  • Advanced HA, EFI, Intel TDX, CPU flags, architecture, ECC, VLAN, and PCI options

The consolidated VM edit form is not complete in v3.3.0. Use the available row and attached-resource actions for supported live changes.

Known issue in v3.3.0: creating a VM can succeed while form restoration shows a failure notification. The virtual machine is still created.

Under the Hood

How Electros works behind the scenes

Electros is a desktop app backed by core services for the targets you register. Atomosphere connects public and private Meson accounts so Electros can provision and operate workloads on those accounts.

Technical Architecture:

  • Desktop app for Linux, macOS, and Windows
  • Atomosphere connectivity for registered Meson accounts
  • Embedded VNC for long-lived VMs, and desktop SSH for reachable Spot VMs
  • VM, storage, and networking actions on the relevant resource page
  • Host selection using provider, region, sizing, availability, and sustainability information

Frequently Asked Questions

Common questions about Electros functionality

How do I get started?

If you do not have an Elemento account yet, create one first — you get an organisation and a 14-day free trial. If you already have an account, open Buy a seat to purchase for an organisation via Stripe.

Where do I pay?

On the Buy a seat page, sign in, choose an organisation and plan, then Stripe opens in your browser. Subscribe during the trial so you do not lose access when it ends.

Does Electros run offline?

Electros caches selected static resources for a more resilient desktop experience. Managing live resources still requires connectivity to the relevant target and Elemento services.

Which operating systems are supported?

Native desktop apps for Linux, macOS, and Windows. v3.3.0 publishes nine installers: Linux x64 and ARM64 AppImage, Debian/Ubuntu x64 and ARM64 DEB, RPM-based Linux x64 and ARM64 RPM, macOS Intel x64 and Apple Silicon ARM64 DMG, and Windows x64 EXE.

What access protocols are supported?

Open an embedded VNC console for long-lived virtual machines. For public-cloud Spot VMs, the Electros desktop app can open an SSH terminal to a reachable instance. SSH Terminal requires a running Spot VM with a reachable public IPv4 address and TCP port 22. Browser builds cannot open the desktop SSH window.

Is Electros free to use?

New accounts get a 14-day free trial once. After that, each organisation needs an Electros seat subscription — one seat per organisation. Sign in above to buy a seat; checkout opens in Stripe.
