Who Electros is for

One desktop app. Four ways teams use it on the first day.

Platform teams and MSPs

Split quotas with sub-organisations. Invite people onto a paid tier. Cap VMs, CPU, RAM, storage and which network types a team may create.

Hybrid labs

Bundle AtomOS, Proxmox and ESXi into a scenario. Enable the stack for this session and the host picker fills with that lab only.

Developers

Burst a Spot VM on a public-cloud Meson account, open desktop SSH when the guest is reachable, then Terminate so billing stops.

App teams

Order Postgres, a managed Kubernetes cluster, or an n8n app from the same create flow — where those services are enabled for the organisation.

Frequently Asked Questions

Trial, seats, targets, and what the desktop app can do today

How do I get started?

If you do not have an Elemento account yet, create one first — you get an organisation and a 14-day free trial. If you already have an account, open Buy a seat to purchase for an organisation via Stripe.

Where do I pay?

On the Buy a seat page, sign in, choose an organisation and plan, then Stripe opens in your browser. Subscribe during the trial so you do not lose access when it ends.

Does Electros run offline?

Electros caches selected static resources for a more resilient desktop experience. Managing live resources still requires connectivity to the relevant target and Elemento services.

Which operating systems are supported?

Native desktop apps for Linux, macOS, and Windows. v3.3.0 publishes nine installers: Linux x64 and ARM64 AppImage, Debian/Ubuntu x64 and ARM64 DEB, RPM-based Linux x64 and ARM64 RPM, macOS Intel x64 and Apple Silicon ARM64 DMG, and Windows x64 EXE.

Download Electros

What access protocols are supported?

Open an embedded VNC console for long-lived virtual machines. For public-cloud Spot VMs, the Electros desktop app can open an SSH terminal to a reachable instance. SSH Terminal requires a running Spot VM with a reachable public IPv4 address and TCP port 22. Browser builds cannot open the desktop SSH window.

Is Electros free to use?

New accounts get a 14-day free trial once. After that, each organisation needs an Electros seat: Start is €19.90 per month billed annually (€239 / year, or €30 monthly), Grow is €39.90 per month billed annually (€479 / year, or €60 monthly). One seat per organisation.

Does registering a target provision anything?

No. Connections is an address book. Enabling a target or a scenario under Active Connections is what makes it appear in host pickers and IaaS lists. Create still happens in a separate wizard.

Desktop app or browser?

The native app for Linux, macOS, and Windows is the product. Spot VM SSH and wallpaper import need the desktop app. Browser builds cannot open those windows.

Which clouds can I bring?

Public Meson accounts your organisation already allows, plus private Meson credentials. Private Meson guides are currently available for AWS, Azure, Google Cloud, OVHcloud, UpCloud and Scaleway.

Can I limit what each team uses?

Yes. Create a sub-organisation with caps on VMs, CPU, RAM, storage and allowed network types. Usage and permissions choose who may use a target or a scenario. Your plan’s connection quota caps how many targets you can enable at once.

What does a Spot VM cost when I am done?

Terminate deletes the instance and stops billing for it. Leaving a Spot VM running is what the bill is for. Some create flows also open a payment page after a successful create.
